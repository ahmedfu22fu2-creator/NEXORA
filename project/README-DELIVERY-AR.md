# THE SQUAD v203 — حزمة المشروع والتسليم

هذه الحزمة هي نسخة المشروع الموجودة في الملف المرسل، مع الحفاظ على شجرة `source/` و`site/` و`backend/` والأصول والاختبارات والملفات التاريخية. تمت إضافة تقارير التسليم والتدقيق فقط؛ لم يتم حذف الملفات القديمة.

## التشغيل المحلي
1. ثبّت Node.js بإصدار 20.19 أو أحدث.
2. من مجلد المشروع شغّل `npm install`.
3. شغّل `npm test` للتحقق من الاختبارات الآلية.
4. لتشغيل واجهة الموقع: `npm run dev` من جذر المشروع إذا كانت Vite مثبتة.
5. إعدادات Firebase والأسرار تُضبط في بيئة الخادم/لوحة Firebase فقط. لا تضع مفاتيح الخدمة أو الأسرار في ملفات المتصفح.

## البناء والنشر
- أمر البناء: `npm run build`.
- إعداد Firebase Hosting يوجه إلى مجلد `dist`.
- لا تنشر هذه النسخة على الإنتاج قبل نجاح بناء Vite واختبار Firebase في مشروع staging.
- لا يحتوي هذا التسليم على أسرار Firebase أو بيانات اعتماد TURN حقيقية، ولا يمكن إنشاء رابط نشر دون صلاحية إلى حساب الاستضافة.

## نتائج التحقق الحالية
- `npm test`: ناجح بالكامل في بيئة التسليم.
- `npm run build`: لم يكتمل؛ البيئة أعادت `vite: Permission denied`. راجع `V203-HANDOFF-AR.md`.
- لم يتم إجراء اختبار حي على Firebase أو اختبار متصفح حقيقي/أجهزة متعددة.

## نقاط مهمة
الخطة المرفقة تصف منتجاً ضخماً، وليست دليلاً على اكتمال كل ميزة. راجع `V203-ROADMAP-AUDIT-AR.md` لمعرفة ما تثبته الملفات والاختبارات وما يحتاج إلى تنفيذ أو اختبار لاحق.

## تحديث v211
راجع `V211-RELEASE-NOTES-AR.md` و`BUILD-STATUS-v211.md` لتفاصيل الجراج ثلاثي الطوابق، المرور الآلي، تصادم الأثاث، ومزامنة تصميم الغرف عبر Firestore. يجب نشر قواعد Firestore على مشروعك قبل تفعيل الحفظ السحابي، كما أن بناء Vite يحتاج تثبيت الاعتماديات.
