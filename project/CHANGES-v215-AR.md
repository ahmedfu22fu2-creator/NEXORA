# THE SQUAD v215 — تأسيس خدمات الجراج المعتمدة على الخادم

## ما تم تنفيذه في الكود
- إضافة Cloud Callable باسم `garageAction` يتحقق من ملكية السيارة من مستند `economy/{uid}` الخاص بالحساب، ويستخدم ترحيل مفاتيح السيارات الحالي؛ لا يعتمد على LocalStorage أو قيمة ملكية يرسلها المتصفح.
- إضافة فحص بوابة `gateCheck` يسجل نتيجة السماح بعد التحقق الخادمي.
- إضافة استقبال طلبات Valet وطلب استدعاء السيارة في `garageServiceRequests` مع حد زمني 15 ثانية لكل حساب.
- إضافة `getGarageAdminOverview` محمي بنفس تحقق حساب الإدارة الحالي، ويعيد حجوزات المواقف وطلبات الخدمة وسجل البوابات.
- إضافة واجهة داخل الجراج لاختيار سيارة مملوكة وإرسال فحص البوابة وطلب Valet وطلب الاستدعاء.
- منع وصول العميل المباشر إلى سجلات طلبات الخدمة وسجلات البوابات وحدود الطلبات في قواعد Firestore؛ الكتابة تتم عبر Admin SDK.
- تحديث نسخة المشروع إلى v215 مع الحفاظ على الطوابق والمنحدرات والمواقف والكاميرات المجسمة الموجودة.

## ما لا يزال غير مكتمل
- البوابة حتى الآن تحقق خادمي وتسجل السماح؛ لم يتم ربطها بباب/حاجز متحرك في مشهد Three.js.
- Valet والاستدعاء يسجلان طلباً في قائمة انتظار؛ لم يتم بعد تنفيذ تحريك السيارة فعلياً أو اختيار مسار آمن أو تسليم السيارة للاعب.
- الكاميرات الموجودة مجسمات ثلاثية الأبعاد فقط؛ لا يوجد بث حي أو تسجيل أو اختيار كاميرا من لوحة المراقبة.
- أُنشئت دالة ملخص إدارة الجراج المحمية، لكن لم تُربط بعد بواجهة مرئية داخل لوحة الإدارة.
- مزامنة الحجوزات في v214 ما زالت تتطلب نشر قواعد Firestore واختبار حسابين حقيقيين.

- لم يتم نشر Cloud Functions أو قواعد Firestore على مشروع Firebase.
- لم يتم اختبار حساب فعلي يملك سيارة وحساب لا يملكها.
- لم يتم اختبار المشهد في متصفح WebGL أو اختبار اللاعبين المتزامنين.
- لم يتم تنفيذ `npm test` الكامل أو `npm run build`؛ لا توجد `node_modules` أو ملف lock في النسخة المستخرجة.
