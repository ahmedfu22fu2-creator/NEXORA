## التحسينات المنفذة
1. **مركز جودة جديد:** نافذة عربية متجاوبة مرتبطة بمنطقة أدوات الصفحة الاجتماعية.
2. **فحوصات توافق محلية:** حالة التخزين المحلي، Service Worker، WebGL، HTTPS، وتفضيل تقليل الحركة.
3. **تصدير البيانات المحلية:** إنشاء ملف JSON على جهاز المستخدم للإعدادات المتاحة من مراحل v268–v271. لا تُرسل البيانات إلى أي خدمة خارجية.
4. **إدارة إعدادات الخصوصية:** حذف إعدادات الخصوصية والأسماء المستعارة المحلية فقط بعد تأكيد المستخدم. لا يحذف ذلك الحساب أو بيانات Firebase أو المحتوى المنشور.
5. **إتاحة الوصول:** دلالات Dialog، إغلاق بزر Escape، حصر التنقل بلوحة المفاتيح داخل النافذة، استعادة التركيز، ومراعاة الشاشات الصغيرة وتقليل الحركة.
6. **تكامل الإصدار:** تحديث صفحة التشغيل وService Worker وملفات version.json العشرة ونسخ source/handoff، وإضافة اختبار v272 إلى مساري الاختبار الرئيسيين.
