# تغييرات v216 — تشغيل الجراج

- إضافة 12 منظور كاميرا ثلاثي الأبعاد قابل للاختيار داخل شاشة مراقبة الجراج.
- إضافة ذراع بوابة متحرك يفتح بعد موافقة خدمة التحقق من ملكية السيارة.
- إضافة تحريك محلي للسيارة في طلب Valet أو الاستدعاء، مع فحص العوائق وإيقاف الحركة عند الاصطدام.
- إضافة لوحة جراج إدارية داخل المدينة: عرض الحجوزات والطلبات وسجلات البوابات، تحرير الحجز، وفتح/إغلاق موقف.
- إضافة `garageAdminAction` محمية بصلاحية الإدارة، مع سجل تدقيق خاص.
- منع العميل من قراءة/تعديل مجموعات إعدادات المواقف وسجل التدقيق مباشرة.
- تحديث المرايا والاختبارات وملفات الإصدار.

حدود معروفة: حركة السيارات محلية وغير متزامنة بين اللاعبين؛ الكاميرات تعرض منظوراً داخل جلسة المستخدم فقط ولا تسجل؛ لا يوجد توجيه مسارات للـValet؛ لم يتم نشر Firebase أو اختبار حسابين فعليين.
