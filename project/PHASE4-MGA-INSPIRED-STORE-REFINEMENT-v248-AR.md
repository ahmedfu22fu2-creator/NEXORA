# تقرير المرحلة v248 — تطوير متجر THE SQUAD بأفكار MGA

## الهدف
نقل أنماط التصميم والتفاعل المناسبة من مشروع MGA إلى متجر THE SQUAD، مع الاحتفاظ باسم THE SQUAD والكتالوج الحالي ونظام الشراء الحالي.

## ما نُفذ
- إنشاء شريط حملات/إعلانات داخلي متحرك مستوحى من أسلوب MGA: تنقل سابق/التالي، نقاط، توقف عند التفاعل، وتوقف عند إخفاء الصفحة.
- محتوى الإعلان يُبنى من عناصر كتالوج THE SQUAD الحالية فقط، ويتغير مع تصنيف المتجر النشط. لم تُنقل صور أو روابط أو هوية MGA.
- إنشاء قسم «مختارة لك» يرتب العناصر حسب تصنيفات استكشفها المستخدم أو تفاعل معها. الإشارات عبارة عن عدادات تصنيف محلية على نفس الجهاز فقط؛ لا أسماء أو بيانات حساب أو تتبع خارجي.
- تصميم داكن متوافق مع هوية THE SQUAD، متجاوب مع الهاتف، مع دعم تقليل الحركة ولوحة المفاتيح.
- الحفاظ على عناصر الكتالوج الـ11 وعلى `economyGet` و`economyAction` وعمليات `buyCar` و`buyEstate` و`buyApartment` دون تغيير.
- تحديث نسخ المصدر والمرايا وأرقام الإصدار وذاكرة Service Worker.

## ما لم يُنقل من MGA ولماذا
لم يتم نسخ Firebase الخاص بـMGA أو قواعده أو لوحة إدارة متجره أو الطلبات أو واتساب أو Amazon أو التتبع أو صور المنتجات التجارية؛ لأنها غير متوافقة مع متجر العناصر الافتراضية وقد تكشف بيانات أو تخلط قواعد مشروعين منفصلين. لم يتم إنشاء لوحة إدارة إعلانات أو نظام إعلانات مدفوعة؛ الموجود في هذه المرحلة حملات داخلية مبنية على مخزون THE SQUAD الحالي.

## الاختبارات
- PASS: فحص تكامل v248، تطابق صفحة المتجر مع مرآة المصدر، بقاء 11 عنصرًا، الحفاظ على مسارات الشراء الخادمية، التحقق من اسم THE SQUAD، عدم وجود هوية MGA/روابطها/تتبعها في الإضافة، صحة JavaScript، تحديث نسخ الإصدار وملفات Service Worker.
- PASS: مجموعة `npm test` الكاملة بعد تحديث اختبار التوافق التاريخي v247؛ جميع الاختبارات المدرجة انتهت بنجاح، بما فيها فحص الإنتاج و151 عنصرًا في precache.
- BLOCKED: `npm run build` لأن Vite غير مثبت في بيئة التنفيذ (`vite: not found`).
- NOT TESTED: جلسة Firebase حية، عمليات شراء فعلية، اختبار بصري داخل متصفح حقيقي، نشر GitHub Pages، أو مزامنة إعلانات من لوحة إدارة.
