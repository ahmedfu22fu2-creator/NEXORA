# تقرير المرحلة الثالثة — الحسابات والخصوصية (v221)

## ما تم تنفيذه
- توسيع إعدادات الخصوصية داخل خطوة إنشاء الحساب: خصوصية الصورة الشخصية، وآخر ظهور، والجمهور الافتراضي للحالات، مع الاحتفاظ بخيارات الهاتف وتاريخ الميلاد.
- حفظ إعدادات الخصوصية الجديدة داخل `users/{uid}.pv` عند إنشاء الحساب.
- إضافة خيار خصوصية الصورة الشخصية في إعدادات الحساب الحالية.
- تعديل قاعدة Firestore لتطبيق إعداد خصوصية الصورة فعليًا عند قراءة `photos/{uid}`: الكل / جهات الاتصال / لا أحد. القاعدة تعتمد على `canSee` الموجودة بالفعل، مثل خصوصية آخر ظهور.
- الإبقاء على إعداد آخر ظهور والجمهور الافتراضي للحالات الموجودين، وإظهارهما أيضًا في التسجيل.
- إضافة Cloud Function باسم `revokeMySessions` لإبطال refresh tokens للحساب، وربطها بخيار «تسجيل الخروج من كل الأجهزة» في شاشة الأمان. بعد نجاح العملية يتم تسجيل خروج الجهاز الحالي أيضًا.
- الحفاظ على تغيير كلمة المرور الحالي، وإعداد «ابقَ مسجلاً»، وتسجيل الخروج المحلي دون حذفها أو استبدالها.
- تحديث Service Worker cache namespace وبيانات المرحلة إلى v221، وإضافة اختبارات تحقق ثابتة جديدة.

## ما لم يكتمل بعد
- **حذف الحساب نهائيًا غير منفذ في هذه المرحلة.** لم أضف زرًا يوهم المستخدم بالحذف بينما لا توجد عملية خادم موثوقة تمسح بيانات الحساب والمحتوى المرتبط به بالكامل. يلزم بناء سياسة حذف شاملة تشمل المنشورات والتعليقات والمحادثات والوسائط والملفات والروابط المرجعية، ثم اختبارها قبل إتاحتها.
- توفر اسم المستخدم أثناء الكتابة ما زال لا يستعلم لحظيًا من الخادم؛ التحقق النهائي عند إنشاء الحساب قائم على قيد Firestore الفريد. التحقق الحي من الرقم الشخصي موجود بالفعل.
- إبطال الجلسات يوقف refresh tokens؛ قد تظل ID tokens الصادرة سابقًا صالحة حتى انتهاء صلاحيتها (عادةً حتى نحو ساعة). الجهاز الحالي يُسجّل خروجه فورًا من التطبيق.

## الاختبارات
- `npm test`: نجح بالكامل، بما في ذلك اختبارات الانحدار السابقة واختبار v221.
- `node --check` لملفات JavaScript المتغيرة: نجح.
- `npm run lint` داخل `backend/firebase-functions`: نجح.
- لم يتم اختبار نشر Cloud Functions أو Firestore Rules على مشروع Firebase الحقيقي، ولا اختبار الدخول/تغيير كلمة المرور/إبطال الجلسات على حساب حقيقي.
- لم يتم نشر GitHub Pages، ولم يتم إجراء اختبار بصري على أجهزة فعلية.

## مطلوب قبل تفعيل الميزات على الموقع المنشور
1. نشر `site/chanse1/firestore.rules` إلى Firestore Rules.
2. نشر `backend/firebase-functions/index.js` إلى Firebase Functions حتى يتوفر `revokeMySessions`.
3. بعد النشر، تجربة حسابين مختلفين للتحقق من أن صورة المستخدم لا تُقرأ إلا حسب إعداد الخصوصية.
4. اختبار إبطال الجلسات على جهازين/متصفحين، مع مراعاة مهلة صلاحية ID token المذكورة أعلاه.

هذه المرحلة تسليم جزئي موثق للحسابات، وليست ادعاءً بأن كل متطلبات المرحلة الثالثة اكتملت.
