# THE SQUAD — تشغيل طلبات الجراج v218

## ما أُضيف
- Callable `getGarageServiceStatus`: يسمح لصاحب الطلب فقط بقراءة حالة طلبه؛ لا تُفتح قراءة مجموعة الطلبات للمتصفح.
- دورة حالات محددة لطلبات Valet والاستدعاء: `queued → accepted → completed`، مع إمكانية الإلغاء من الحالات المسموح بها.
- إجراءات تغيير الحالة متاحة للإدارة فقط عبر `garageAdminAction`، مع التحقق من انتقال الحالة داخل Firestore transaction وتسجيل العملية في `garageAdminAudit`.
- لوحة إدارة الجراج تعرض أزرار قبول/رفض للطلبات المنتظرة، وأزرار إنهاء/إلغاء للطلبات المقبولة.
- واجهة اللاعب تتابع حالة طلبه كل 8 ثوانٍ. لا تبدأ الحركة المحلية إلا بعد قبول الإدارة.
- تم توضيح أن حركة السيارة الحالية محاكاة محلية وليست حركة شبكية متزامنة.

## حدود هذه الدفعة
- لم يتم إنشاء سائق Valet مستقل أو مسار ملاحة server-authoritative.
- حركة السيارة بعد الموافقة ما زالت محلية على جهاز صاحب الطلب؛ لا تظهر كحركة مشتركة موثوقة للاعبين الآخرين.
- لا يوجد بث كاميرات مركزي أو تسجيل فيديو.
- لا يوجد نشر Firebase أو اختبار حي بحساب لاعب وحساب إدارة.
