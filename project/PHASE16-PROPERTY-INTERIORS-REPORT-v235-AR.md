# THE SQUAD — المرحلة 16: تصميم وتأثيث العقارات (v235)

## ملخص التنفيذ
تم تطوير طبقة تصميم الغرف الموجودة مسبقًا بدل إنشاء محرر أثاث أو نظام عقارات مكرر. أصبح حفظ تصميم الغرفة مرتبطًا بعقار أو شقة يملكها الحساب، ويجري تحميله وحفظه عبر Cloud Function تتحقق من الملكية على الخادم.

## ما تم تطويره
- ربط تصميم الغرف بالعقار الرئيسي المحدد للحساب، أو بأول عقار/شقة مملوكة عند عدم وجود اختيار رئيسي.
- استخدام الشقة المملوكة عند تصميم طوابق برج الشقق، والعقار المملوك في بقية المباني.
- إضافة Cloud Function باسم `propertyRoomLayout` بعمليتي `load` و`save`.
- التحقق من هوية المستخدم وملكية العقار/الشقة على الخادم قبل قراءة التصميم أو حفظه.
- التحقق الخادمي من معرّف المبنى والطابق والفرع وأنواع الأثاث والإحداثيات، مع حد أقصى 24 قطعة.
- نقل التخزين الجديد إلى مجموعة `propertyRoomLayouts` الخاصة، وعدم السماح بقراءتها أو كتابتها مباشرة من المتصفح؛ عمليات Admin SDK فقط تتجاوز قواعد Firestore.
- الاحتفاظ بالتخزين المحلي كنسخة احتياطية عند غياب تسجيل الدخول أو تعذر الاتصال بالخادم.
- حذف تصميمات العقارات الجديدة عند حذف الحساب.
- إصلاح تكرار حالتي `selectEstate` و`selectApartment` داخل معالج الاقتصاد، دون تغيير سلوكهما.
- تحديث المرايا المصدرية وإصدار المشروع والكاش إلى v235.

## ما بقي كما هو
- أنواع الأثاث الستة الحالية: أريكة، سرير، مكتب، نبات، مصباح، وشاشة.
- أدوات التدوير والتراجع والإفراغ وحد 24 قطعة.
- الأثاث الإجرائي الأصلي، المباني والطوابق والمصاعد، وحركة اللاعب.
- الشراء والملكية والأسعار والاقتصاد الحالي.

## ما لم يكتمل بعد — بوضوح
- لم يتم نشر Cloud Function `propertyRoomLayout` على Firebase.
- لم يتم اختبار القراءة/الحفظ عبر Firebase Emulator أو حسابات حقيقية متعددة.
- لم يتم اختبار التصميم بصريًا على متصفحات وأجهزة فعلية.
- لم تتم إضافة سحب حر للأثاث أو شبكة Grid Snap أو أنواع أثاث جديدة.
- الأثاث الإضافي ما زال طبقة ديكورية؛ نظام التصادم الحالي يستخدم حواجز تقريبية وليس تصادمًا هندسيًا دقيقًا لكل قطعة.
- لم يتم نشر ملفات الموقع على GitHub Pages.

## متطلبات التفعيل
1. نشر Cloud Functions من `backend/firebase-functions` بعد مراجعة إعدادات مشروع Firebase.
2. نشر ملفات الموقع v235 على الاستضافة.
3. تسجيل الدخول بحساب يملك عقارًا أو شقة، والدخول إلى مبنى/طابق، ثم تجربة إضافة قطعة أثاث وإعادة فتح الطابق.
4. التحقق من استمرار التصميم على جهاز آخر بالحساب نفسه.

لا يتطلب هذا المسار فتح صلاحيات Firestore للمتصفح؛ التخزين الجديد يمر عبر الدالة الخادمية فقط، وتظل القراءة والكتابة المباشرتان للمجموعة الجديدة ممنوعتين.
