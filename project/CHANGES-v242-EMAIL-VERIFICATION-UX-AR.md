# THE SQUAD v242 — تحسين التحقق من البريد وإدارة استرداد الحساب

## ما نُفذ
- إضافة بطاقة تحقق البريد داخل الإعدادات ← الأمان وكلمة السر للحسابات المرتبطة ببريد حقيقي.
- إضافة إعادة إرسال رسالة التحقق عبر Firebase Authentication (`sendEmailVerification`).
- إضافة تحديث حالة التحقق عبر إعادة تحميل مستخدم Firebase (`reload`) ثم إعادة رسم الإعدادات.
- معالجة أخطاء الإرسال، بما فيها كثرة الطلبات وفشل الاتصال، برسائل واضحة.
- عدم إظهار إجراء تحقق أو استعادة بريد للحسابات القديمة ذات العناوين الاصطناعية `@squad.id`؛ تظهر بدلاً منه ملاحظة تشرح القيد وتحذر من تغيير بيانات الدخول قبل ترحيل آمن.
- تصحيح رسالة الأمان القديمة التي كانت توحي أن جميع الحسابات بلا بريد أو هاتف، بينما الحسابات الحديثة تملك بريداً حقيقياً.
- مزامنة ملف الإعدادات مع مرآة المصدر، وتحديث بيانات الإصدار وService Worker cache إلى v242.
- تحديث اختبارات التوافق القديمة لتقبل إصدارات لاحقة دون تغيير اختبارات وظائفها التاريخية.

## الحفاظ على التوافق
- لم تتغير آلية تسجيل الدخول أو `usernameLogin`.
- لم تتغير معرفات المستخدمين أو مستندات Firestore أو قواعد الأمان.
- لم تتم محاولة تحويل الحسابات القديمة آلياً إلى بريد جديد؛ هذا يتطلب تصميم ترحيل يحافظ على تسجيل الدخول بالرقم الشخصي واسم المستخدم، ويُختبر على Firebase فعلياً قبل اعتماده.

## الاختبارات
- `npm test`: PASS — اجتازت مجموعة الاختبارات الكاملة، بما فيها اختبارات الانحدار التاريخية واختبار v242 الجديد.
- `node --check` للملفات المعدلة: PASS.
- Production audit وSmoke tests وLocalization وRelease integrity: PASS ضمن `npm test`.
- `npm run build`: BLOCKED — Vite غير مثبت في بيئة التنفيذ (`vite: not found`).
- إرسال البريد الحقيقي وفحص صندوق البريد: NOT TESTED — يتطلب Firebase الفعلي وإعدادات قوالب البريد.
- التحقق من البريد عبر متصفح حي: NOT TESTED.
- ترحيل واسترداد الحسابات القديمة `@squad.id`: NOT TESTED / لم يُنفذ عمداً.

## ما يزال مطلوباً لإغلاق المرحلة الثانية
1. اختبار إرسال رسالة التحقق وإعادة الإرسال على مشروع Firebase الفعلي.
2. اختبار استعادة كلمة المرور للحسابات ذات البريد الحقيقي.
3. تصميم وتنفيذ ترحيل آمن للحسابات القديمة دون كسر الدخول بالرقم الشخصي أو اسم المستخدم.
4. اختبار الدخول والاستعادة على متصفحات وأجهزة فعلية.

لا يُعلن اكتمال المرحلة الثانية في هذا الإصدار.
