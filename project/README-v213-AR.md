# THE SQUAD v213 — دليل التشغيل والتسليم

## التشغيل المحلي
1. ثبّت Node.js بالإصدار الموضح في `package.json` (20.19 أو أحدث).
2. من مجلد المشروع نفّذ: `npm install`.
3. شغّل الاختبارات: `npm test`.
4. شغّل الموقع محلياً: `npm run dev`.
5. لبناء نسخة الإنتاج: `npm run build`.

## الجديد في v213
- منحدران فعليان فيزيائياً داخل جراج المدينة: الأرضي إلى الطابق الثاني، ثم الطابق الثاني إلى الثالث.
- فتحات مخصصة في بلاطات الطوابق ومنصات انتقال مستوية.
- علامات مواقف مرئية: عشرة مواقف لكل طابق.
- واجهة حجز وإلغاء حجز 30 موقفاً.

## تنبيه بشأن الحجز
حجز الموقف في هذا الإصدار محفوظ محلياً في متصفح/جهاز المستخدم، ومربوط بمعرّف الحساب المحلي. لا يُعد حجزاً عالمياً بين اللاعبين ولا يتزامن مع Firebase بعد.

## حالة التحقق
- `npm test`: ناجح.
- `node --check` لملفات محرك المدينة وواجهة المدينة: ناجح.
- `npm run build`: يحتاج تثبيت الاعتماديات أولاً؛ Vite غير متاح في بيئة إنشاء الحزمة الحالية.
- النشر على Firebase أو استضافة حقيقية واختبار WebGL متعدد اللاعبين لم يُنفذا من هذه البيئة.
