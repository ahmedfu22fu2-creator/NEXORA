# THE SQUAD — المرحلة 3 / متجر العالم الافتراضي (v246)

## ما تم تنفيذه
- استبدال صفحة المتجر التعريفية بواجهة عربية متجاوبة بهوية مستقبلية، مع تصفية حسب المركبات والعقارات والشقق.
- ربط عرض رصيد عملة اللعبة بـ `economyGet` بعد التحقق من جلسة Firebase.
- ربط الاقتناء بـ `economyAction` للأنواع الموجودة فعلاً: `buyCar` و`buyEstate` و`buyApartment`.
- الأسعار المعروضة معلومات كتالوج فقط؛ الخادم هو مصدر السعر والملكية، ويخصم من محفظة اللعبة داخل معاملة Firestore. لا يرسل العميل قيمة السعر إلى الخادم.
- مزامنة صفحة المتجر إلى نسخة المصدر، وتحديث manifests وService Worker إلى v246.

## حدود مهمة للدفع الحقيقي
لم يتم إنشاء حساب بنكي أو محفظة دفع أو توجيه عائدات إلى رقم هاتف أو حساب شخصي. الدفع النقدي الحقيقي غير مفعّل. تفعيله يتطلب جهة/حساب تاجر مؤهل ومزود دفع معتمد ومراجعة قانونية وولي أمر عند انطباق ذلك. لم تُخزن أي بيانات دفع أو أرقام شخصية في المشروع.

## الاختبارات
- PASS: `node scripts/v246-in-game-store-check.mjs` — تطابق نسخة المصدر، وجود مسارات Firebase والشراء الخادمي، وحدود الدفع الحقيقي، واتساق manifests.
- NOT TESTED: Firebase حي، رصيد حساب حقيقي، تنفيذ شراء على حساب تجريبي، وربط الملكية الفعلية بعرض العناصر داخل العالم ثلاثي الأبعاد.
- NOT TESTED: `npm test` الكامل و`npm run build`؛ بيئة البناء السابقة لم تكن تحتوي Vite مثبتاً، والاختبار الشامل يتضمن فحصاً تاريخياً متعارضاً مع manifests الحديثة.
- لم يتم نشر Cloud Functions أو تغيير Firestore Rules.

## ملاحظات تنفيذية
- المتجر يعتمد على وظائف الاقتصاد الموجودة مسبقاً؛ يجب نشر نسخة Cloud Functions الحالية إذا لم تكن هذه الوظائف منشورة في مشروع Firebase.
- المتجر لا يضيف عناصر جديدة إلى الكتالوج الخادمي؛ يعرض عينة من العناصر الموجودة مسبقاً في قوائم الأسعار المعتمدة.
