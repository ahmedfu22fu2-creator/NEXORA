# تقرير المرحلة 21 — استوديو إنشاء الشخصيات v265

## الهدف
إنشاء تجربة داخل THE SQUAD مستوحاة من واجهة صانع الشخصيات المرجعية، مع هوية بصرية مستقلة وتحسين تجربة الاستخدام.

## المنفذ
- نافذة Creator Lab مستقلة بثلاثة أقسام: Avatar و3D وImage.
- معاينة شكلية مباشرة للشخصية مع خيارات لون البشرة والشعر والملابس والتعبير والإكسسوار والخلفية.
- أربعة قوالب بداية قابلة للتخصيص.
- حفظ إعدادات المظهر محليًا عبر localStorage.
- تصدير ملف JSON لإعدادات الشخصية.
- استقبال ملفات GLB/GLTF محليًا والتحقق من الصيغة والحجم (حتى 100MB) دون رفعها.
- ربط زر الاستوديو من واجهة إعدادات الشخصية.
- دعم لوحة المفاتيح، تصميم متجاوب، واحترام prefers-reduced-motion.
- تحديث Service Worker cache namespace وprecache assets ومزامنة مرايا المصدر وhandoff.
- لم يتم تغيير Firebase أو صلاحيات الحسابات أو رفع صور/نماذج إلى الخادم.

## حدود صريحة
المعاينة الحالية رسم تصميمي CSS وليست مجسمًا ثلاثي الأبعاد فعليًا. استيراد GLB/GLTF يلتقط الملف محليًا ويعرض اسمه فقط؛ لا يوجد بعد عارض GLTF أو تحويل نص/صور إلى mesh أو rigging أو lip-sync للنموذج المستورد. الصور المرجعية لا تُرسل إلى خدمة خارجية.
