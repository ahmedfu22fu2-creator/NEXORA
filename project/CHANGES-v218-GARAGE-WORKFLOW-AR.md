# THE SQUAD v218 — دورة تشغيل خدمات الجراج

- أضيف استعلام حالة طلب محمي بملكية UID.
- أضيفت انتقالات حالة موثوقة على الخادم: queued → accepted → completed، مع الإلغاء في الحالات المسموح بها.
- جميع تغييرات الحالة الإدارية تمر عبر صلاحية الإدارة ومعاملة Firestore وسجل التدقيق.
- لوحة الإدارة تعرض إجراءات قبول/رفض/إنهاء/إلغاء طلبات الخدمة.
- اللاعب يتابع حالة الطلب، ولا تبدأ الحركة المحلية قبل موافقة الإدارة.
- لا تدّعي هذه النسخة وجود مزامنة حركة للسيارات أو بث كاميرات مركزي؛ هذه ما زالت أعمالاً لاحقة.
