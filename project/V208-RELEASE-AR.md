# THE SQUAD v208 — المدينة ثلاثية الأبعاد وقيادة السيارات

## المنفذ في هذه النسخة

- إضافة شاشة قيادة داخل المدينة تعرض السرعة الحالية بوحدة كم/س.
- إضافة مؤشر تلقائي لحالة ناقل الحركة: N محايد، D أمامي، R رجوع.
- إضافة لوحة لمس للهواتف تشمل التسارع والرجوع والتوجيه يميناً ويساراً والفرامل.
- ربط أزرار اللمس مباشرة بمدخلات نظام القيادة والفيزياء الحالي، دون إنشاء محرك قيادة منفصل.
- إضافة التقاط المؤشر وإطلاقه عند رفع الإصبع أو إلغاء اللمس لتفادي استمرار التسارع أو التوجيه بالخطأ.
- إظهار لوحة القيادة عند ركوب سيارة وإخفاؤها عند النزول، مع تصفير المدخلات.
- الإبقاء على المدينة والمباني الداخلية والسيارات الإجرائية والملكية والتحقق من صلاحية القيادة ومزامنة السيارة متعددة اللاعبين.
- تحديث رقم الإصدار وذاكرة Service Worker، مع مزامنة نسخة المصدر مع نسخة الموقع.

## التحكم

- الكمبيوتر: W تسارع، S رجوع، A/D توجيه، Space فرامل، E للنزول.
- الهاتف: أزرار الشاشة للتسارع والرجوع والتوجيه والفرامل.

## الاختبارات

- `npm test`: ناجح بالكامل، بما يشمل تدقيق الإنتاج واختبارات التوافق السابقة واختبار v208.
- `node --check site/chanse2/district.js`: ناجح.
- `node scripts/v208-driving-suite-check.mjs`: ناجح.
- `npm run build`: لم يعمل في بيئة التجهيز لأن Vite غير مثبت (`vite: not found`).

## ما لم يتم ادعاء اكتماله

لم يتم تشغيل متصفح WebGL أو تجربة فعلية على هاتف، ولم يتم نشر Firebase أو اختبار اصطدامات/تزامن قيادة حي بين مستخدمين على بيئة إنتاج. يلزم تشغيل النسخة على استضافة المشروع وإجراء اختبار أجهزة حقيقية قبل اعتماد القيادة كإصدار إنتاجي.
