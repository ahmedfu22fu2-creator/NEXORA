# تقرير المرحلة v251 — تطوير الصفحة الرئيسية وتجربة المنشورات

## الهدف
تطوير تجربة الصفحة الرئيسية الاجتماعية الحالية في THE SQUAD، وتحسين عرض المنشورات والصور والتنقل والأداء، مع إصلاح مسار التصفح المتدرج للمنشورات العامة. لم تتم إضافة نظام اجتماعي مكرر أو تغيير مخطط Firebase.

## ما تم تنفيذه

### 1. تحسين عرض المنشورات
- إعادة تنسيق بطاقات المنشورات لتتوافق مع هوية THE SQUAD الداكنة مع البنفسجي/الأزرق ولمسات ذهبية من الهوية الحالية.
- تحسين المسافات ووضوح النصوص والرأس والإحصاءات وأزرار التفاعل.
- تحسين عرض الصور المفردة والمتعددة، مع مساحة تحميل وحالة فشل واضحة.
- إضافة `decoding="async"` للصور و`loading="lazy"`.
- إضافة تسميات وصول لأزرار خيارات المنشور، وحالة `aria-pressed` لأزرار الإعجاب والحفظ.
- تحسين حالات التحميل والخطأ والفراغ وإعادة المحاولة.

### 2. تحسين تحميل الصور
- أصبح تحميل صور المنشورات المتعددة متوازيًا بدلًا من تحميلها بالتتابع.
- يتم تحديث حاوية الصور في البطاقة الحالية فقط بعد اكتمال التحميل، دون إعادة كتابة كامل `#dr-screen`.
- هذا يمنع فقدان حالة أدوات البحث/التصفية أو إعادة بناء عناصر الفيد بسبب انتهاء تحميل الصور.
- الاحتفاظ باستخدام Firebase Storage الحالي ومسارات الصور نفسها.

### 3. إصلاح استكمال الفيد العام
- إضافة cursor pagination لاستعلام المنشورات العامة الأكثر تفاعلًا باستخدام `startAfter`.
- زر «تحميل المزيد» يستطيع الآن متابعة صفحات الفيد العام بدل التوقف بعد أول 10 منشورات.
- إعادة ضبط مؤشر التصفح عند بدء تحميل فيد جديد.
- الحفاظ على مسار منشورات المتابَعين الحالي وعلى نفس استعلام Firestore الأساسي.

### 4. التصميم المتجاوب وإمكانية الوصول
- تحسين بطاقات المنشورات على الهواتف والشاشات الصغيرة.
- توزيع أزرار التفاعل على شبكة مرنة للموبايل.
- دعم `prefers-reduced-motion`.
- تحسين مؤشرات التركيز بلوحة المفاتيح.

### 5. سلامة الإصدار
- تحديث الإصدار إلى v251 في الحزم والـ manifests.
- تحديث مساحة التخزين المؤقت في Service Worker وإضافة CSS الجديد إلى precache.
- مزامنة نسخة `social-feed.js` وService Worker وملفات الإصدار مع مرآة المصدر `source/The-Squad-v137`.
- تحديث اختبارات المراحل السابقة التي كانت ترفض أرقام إصدارات أحدث من v249/v250، دون تعطيل فحوص وظائفها.

## حدود مهمة
- لم يتم تغيير قواعد Firestore أو Storage أو Cloud Functions.
- الفيد العام يستخدم نفس الحقول والاستعلامات الأساسية الموجودة؛ أضيف فقط مؤشر متابعة الصفحات إلى استعلامه القائم. يجب التأكد من توافر الفهرس المركب نفسه في Firebase عند الاختبار الحي.
- لم يتم الادعاء بقياس FPS أو زمن تحميل فعلي؛ تحسين التوازي وتجنب إعادة بناء DOM تم التحقق منهما باختبارات ثابتة فقط.
- لا يتضمن هذا الإصدار نشرًا إلى GitHub Pages أو تعديلًا لبيانات المستخدمين.

## النتيجة
تم تنفيذ تطوير واجهة الصفحة الاجتماعية وتحسين تحميل الصور واستكمال التصفح العام في الكود، واجتازت الاختبارات الثابتة وسلامة الإصدار. الإصدار ليس إثباتًا لاختبار الإنتاج؛ يلزم إكمال بناء Vite واختبار Firebase والمتصفح قبل النشر العام.
