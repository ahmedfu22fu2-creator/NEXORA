# تقرير المرحلة 1 — الهوية والتصميم | THE SQUAD v219

## النسخة الاحتياطية
تم إنشاء `THE_SQUAD_v218_BACKUP_BEFORE_PHASE1.zip` قبل تعديل ملفات المرحلة.

## ما تم تنفيذه
- اعتماد لوحة موحدة: خلفية `#0B0C10`، نص `#F5F5F7`، وذهبي `#D4AF37` كلون تمييز أساسي.
- إنشاء `site/v219-brand-system.css` كمصدر مركزي للمتغيرات، مع ربط المتغيرات القديمة به لتقليل مخاطر كسر الشاشات الحالية.
- اعتماد زوايا أساسية 12/14/16px وظلال عميقة وزجاج داكن خفيف.
- تحديث شعار SVG وأيقونات PNG بمقاسات 192 و512 ونسخة maskable، مع تحديث أيقونة Apple Touch.
- تحديث ألوان وبيانات PWA manifest وعنوان الصفحة وبيانات العلامة.
- إضافة IBM Plex Sans Arabic إلى خطوط الويب مع الإبقاء على Inter وSora للإنجليزية.
- إضافة اختبار تحقق خاص بالهوية v219 إلى مجموعة اختبارات المشروع.

## الملفات التي تغيرت
- `site/index.html`
- `site/sw.js` (إضافة ملفات الهوية إلى قائمة التخزين المؤقت دون تغيير مساحة إصدار Service Worker القديمة)
- `package.json`, `site/package.json` (إضافة اختبار المرحلة دون كسر اختبارات الإصدار السابق)
- `site/chanse4/tokens.css` (لم يتغير محتواه؛ تم تجاوز قيمه عبر طبقة العلامة الجديدة)
- `site/v219-brand-system.css` (جديد)
- `site/chanse4/icon.svg`
- `site/chanse1/manifest.json`
- `site/chanse1/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
- `site/chanse3/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
- `site/chanse2/apple-touch-icon.png`
- `scripts/v219-brand-identity-check.mjs` (جديد)
- `package.json`, `site/package.json`

## ما لم يتم في هذه المرحلة
- لم يتم تنفيذ شاشة الباب/تسجيل الدخول الجديدة؛ هذه هي المرحلة 2.
- لم يتم تغيير منطق Firebase Auth أو Firestore.
- لم يتم نشر GitHub Pages أو Firebase.
- لم يتم تعديل أنظمة التواصل أو المدينة أو الجراج.

## الاختبارات
- اختبار تحقق الهوية v219: يُشغّل محلياً عبر `node scripts/v219-brand-identity-check.mjs`.
- بناء Vite واختبار المتصفح الفعلي لم يتمّا في هذه البيئة حتى إعداد التقرير.
- الخطوط الخارجية تعتمد على اتصال Google Fonts؛ توجد بدائل fallback في CSS.

## ملاحظة توافق
الطبقة الجديدة تضيف متغيرات وتعيد توجيه متغيرات التصميم القديمة، ولا تحذف ملفات CSS أو وظائف قديمة. قد تظل بعض الألوان المكتوبة مباشرة داخل ملفات قديمة خارج نظام المتغيرات؛ مراجعتها تتم تدريجياً دون إعادة تصميم جماعي غير آمن.
