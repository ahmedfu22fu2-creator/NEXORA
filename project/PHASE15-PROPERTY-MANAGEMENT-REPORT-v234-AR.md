# THE SQUAD — المرحلة 15: العقارات والمنازل (v234)

## ملخص التنفيذ
تمت مراجعة نظام العقارات الموجود في `site/chanse2/district.js` ومحرك الاقتصاد في Cloud Functions. كان المشروع يحتوي بالفعل على كتالوج الفلل والقصور والشقق، وشراء مملوك للخادم، ودخول العقار، وموظفي العقارات. لذلك لم تتم إضافة متجر مكرر أو نظام إيجار غير متكامل.

ركزت المرحلة على إكمال وظيفة إدارة مهمة ومفقودة: **تعيين السكن الرئيسي ومزامنته مع الحساب عبر Firebase**.

## ما تم تطويره
- إضافة عمليتي اقتصاد خادميتين:
  - `selectEstate`: تعيين عقار مملوك كسكن رئيسي.
  - `selectApartment`: تعيين شقة مملوكة كسكن رئيسي.
- التحقق على الخادم من أن العقار/الشقة موجود في الكتالوج المعتمد وأنه مملوك للحساب نفسه قبل حفظ الاختيار.
- حفظ `selectedEstate` و`selectedApartment` داخل مستند الاقتصاد الخاص بالحساب، وإعادتهما مع حالة الاقتصاد.
- عرض زر «تعيين كسكن رئيسي» لكل عقار أو شقة مملوكة، مع تمييز السكن المحدد حاليًا.
- تحديث الاختيار مباشرة بعد نجاح العملية وإعادة رسم لوحة العقارات.
- مزامنة التعديلات مع نسخ `district.js` وCloud Functions المرجعية داخل مجلدات المصدر ونسخة التسليم.
- تحديث إصدار الموقع والكاش إلى v234.
- إضافة اختبار انحدار مستقل للمرحلة 15، وربطه بسلسلة الاختبارات الكاملة.

## ما لم يتم تغييره عمدًا
- لم يتم إنشاء نظام إيجار أو بيع/نقل ملكية بين اللاعبين؛ لأن ذلك يحتاج قواعد مالية وملكية وتوافقًا مع تجربة اللعب أوسع من مجرد واجهة.
- لم يتم تغيير أسعار العقارات أو بيانات الكتالوج أو نظام شراء العقارات الحالي.
- لم يتم تغيير قواعد Firestore؛ عمليات التعيين تتم من خلال `economyAction` الخادمية ولا تضيف كتابة مباشرة من المتصفح.
- لم يتم تعديل نظام الحراس والخدم أو طريقة الدخول إلى العقارات والشقق.

## الاختبارات
- `npm test`: **نجح بالكامل**، بما في ذلك جميع اختبارات المشروع السابقة واختبار v234 الجديد.
- `node --check` لكل ملفات JavaScript المعدّلة: **نجح**.
- اختبار المرحلة 15: **نجح**.
- فحص سلامة ملفات المصدر والمرايا: **نجح**.
- `npm run build`: **لم يكتمل**؛ Vite غير مثبت في بيئة التنفيذ (`vite: not found`).

## ما لم يكتمل بعد — بوضوح
- لم يتم نشر Cloud Functions على Firebase؛ لذلك اختيار السكن الرئيسي السحابي لن يعمل في الموقع الحي قبل نشر الدوال.
- لم يتم اختبار حفظ الاختيار بين جهازين حقيقيين أو عبر Firebase Emulator.
- لم يتم نشر الموقع على GitHub Pages.
- لم يتم إجراء اختبار بصري فعلي داخل المدينة أو على أجهزة موبايل.
- لم يتم إنشاء نظام إيجار أو بيع أو نقل ملكية أو إدارة فواتير وصيانة؛ هذه وظائف مستقلة وليست جزءًا من هذه الدفعة.

## النشر
بعد مراجعة الإعدادات والنسخ الاحتياطية، انشر Cloud Functions من `backend/firebase-functions` أولًا، ثم انشر ملفات الموقع v234 على GitHub Pages. لا توجد حاجة لتغيير Firestore Rules لهذه الميزة تحديدًا. اختبر بحساب يمتلك عقارين/شقتين، وعيّن أحدهما سكنًا رئيسيًا، ثم سجّل الدخول بالحساب نفسه من جهاز آخر للتحقق من ظهور الاختيار.
