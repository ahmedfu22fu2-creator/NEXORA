# تقرير المرحلة الثانية — الباب وشاشة الدخول (v220)

## النسخة الاحتياطية
تم إنشاء `THE_SQUAD_PHASE1_BACKUP_BEFORE_PHASE2.zip` قبل أي تعديل. لم يتم حذف ملفات المرحلة الأولى أو استبدال نظام Firebase Auth الحالي.

## ما تم تنفيذه
- مشهد باب سينمائي CSS دون WebGL: أول ثانية ظلام، ثم ضباب وظهور الباب وإطاره وتفاصيله، ثم ضوء الحواف وانعكاس الأرض، ظهور اسم THE SQUAD، بداية فتح الباب عند 5.5 ثانية، وظهور نموذج الدخول عند 7 ثوانٍ.
- زر تخطي.
- المشهد المختصر للزيارة التالية مدته 1.5 ثانية.
- وضع ثابت خفيف للأجهزة منخفضة الذاكرة/المعالج، واحترام إعداد تقليل الحركة.
- الصوت اختياري ومكتوم افتراضياً ولا يعمل إلا بعد تفاعل المستخدم.
- إعادة تصميم بطاقة الدخول بألوان الهوية المعتمدة، مع الإبقاء على حقول ومسارات Firebase Auth والتسجيل متعدد الخطوات.
- الرقم الشخصي يظهر بفواصل بصرية كل 3 أرقام، مع الحفاظ على قيمة رقمية نظيفة قبل إرسالها إلى Firebase. لا يزال البريد الإلكتروني واسم المستخدم القديم مدعومين للتوافق.
- عداد إدخال 0/10.
- خيار «ابقَ مسجلاً» مفعّل افتراضياً، ومربوط باختيار Firebase LOCAL أو SESSION persistence.
- رسائل أوضح لكلمة المرور الخاطئة، والحساب غير الموجود، وانقطاع الإنترنت، وكثرة المحاولات.
- تحديث Service Worker cache وإضافة الأصول الجديدة إليه، مع إبقاء بيانات إصدار المنصة الأساسية متوافقة مع اختبارات الإصدارات السابقة وإضافة `featurePhase: 220`.

- لم يتم إجراء اختبار بصري على أجهزة فعلية متعددة أو قياس Lighthouse.
