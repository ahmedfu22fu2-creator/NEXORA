# NEXORA — تسليم تغيير الاسم وتطبيق الويب

## نطاق العمل
تم تنفيذ المطلوب فقط: تغيير الهوية الظاهرة إلى **NEXORA** وتجهيز التطبيق الحالي للتثبيت كأيقونة على الهاتف/الكمبيوتر، دون إعادة تصميم الصفحات أو تعديل وظائف المنصة.

## ما تم
- تحديث اسم الصفحة وعنوان المتصفح وبيانات التطبيق إلى NEXORA.
- تحديث اسم التطبيق المختصر والوصف في Web App Manifest.
- تصميم أيقونة NEXORA جديدة بطابع أسود/ذهبي احترافي.
- إنشاء مقاسات الأيقونة المطلوبة: 192×192 و512×512 ونسخة Maskable وApple Touch Icon.
- تحديث نسخ المشروع المتطابقة وملفات الخدمة المرتبطة بالاسم الجديد.
- الحفاظ على ألوان وتصميم وتجربة الموقع الحالية دون تغييرها.

## الاختبارات
- **PASS:** `npm test` — جميع اختبارات المشروع المدرجة انتهت بنجاح (exit code 0).
- **PASS:** ملف Manifest قابل للقراءة ويعلن اسم NEXORA ووضع العرض المستقل `standalone`.
- **PASS:** ملفات الأيقونات موجودة وبالمقاسات الصحيحة.
- **PASS:** لا توجد بقايا لعبارة THE SQUAD / The Squad في ملفات واجهة الموقع الأساسية.
- **PASS:** سلامة أرشيف ZIP بعد إنشائه.
- **BLOCKED:** `npm run build` — لم يتوفر Vite كاعتماد مثبت في بيئة التنفيذ، لذلك لم أتمكن من تنفيذ بناء الإنتاج هنا.
- **NOT TESTED:** التثبيت الفعلي على هاتف، وتشغيل Firebase المباشر، والنشر على GitHub Pages.

## طريقة الاستخدام
هذه نسخة **تطبيق ويب قابل للتثبيت (PWA)** وليست ملف APK أصلياً. بعد نشر الموقع عبر HTTPS، يمكن تثبيته من قائمة المتصفح على الأجهزة المدعومة، وسيظهر باسم NEXORA وبالأيقونة الجديدة.

## ملاحظة
الملف المرفق هو المشروع الكامل بعد تغيير الهوية وتجهيز التطبيق. لم يتم الادعاء بأن النشر أو اختبار الأجهزة قد تم.
