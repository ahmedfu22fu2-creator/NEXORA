# تقرير THE SQUAD v273 — Performance & Reliability
التاريخ: 6 نوفمبر 2026

## نطاق التنفيذ
تم فحص أرشيف v272 قبل التعديل، وإنشاء نسخة احتياطية كاملة. يضيف هذا الإصدار مختبر أداء محليًا يعتمد على واجهات المتصفح المتاحة، مع الحفاظ على أنظمة v268–v272.

## التحسينات
1. لوحة أداء تعرض DOMContentLoaded ووقت التحميل وLCP وCLS ومؤشر تفاعل تقريبي وعدد المهام الطويلة.
2. مراقبة محلية لعدد أحداث أخطاء JavaScript والوعود المرفوضة دون تخزين رسائل الخطأ أو إرسالها.
3. عرض حالة الاتصال ونوع الشبكة وإشارة Data Saver، وذاكرة JavaScript عند دعم المتصفح.
4. تصدير تقرير JSON محلي اختياري؛ لا يتضمن روابط أو محتوى أو معرفات شخصية، ولا توجد أي نقطة إرسال أو تحليلات خارجية.
5. واجهة عربية متجاوبة، دعم لوحة المفاتيح وEscape وتقليل الحركة.
6. تحديث صفحة التشغيل وService Worker وبيانات الإصدار ومرايا source/handoff وإضافة اختبار مستقل.

## حدود القياس
- القيم تقريبية وتعتمد على دعم المتصفح ومدة الجلسة؛ مؤشر التفاعل هو أكبر event duration مرصود وليس INP ميدانيًا معتمدًا.
- لا يقيس هذا الإصدار زمن استجابة Firebase أو الخادم أو أداء أجهزة المستخدمين الآخرين.
- لا يرسل بيانات القياس إلى أي جهة.
