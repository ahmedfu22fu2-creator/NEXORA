# تقرير المرحلة الرابعة — الصفحة الرئيسية ومركز التواصل (v223)

## ملخص التنفيذ
تم تطوير الصفحة الرئيسية لتصبح مركز تواصل عمليًا فوق أنظمة The Squad الموجودة بالفعل. التحديث إضافي ويحافظ على نظام Firebase للمحادثات والحالات والقنوات والمجتمعات دون إنشاء مخازن مكررة أو بيانات تجريبية.

## ما تم تنفيذه

1. **شريط الحالات أعلى الصفحة:** يعرض الحالات الفعلية غير المنتهية من بيانات `ST` الحالية، مع اختصار لإضافة حالة جديدة وفتح حالة عضو.
2. **تبويبات الصفحة الرئيسية:** المحادثات، الحالات، القنوات، المجتمعات.
3. **بحث سريع:** البحث في أسماء المحادثات وآخر رسالة، وفي أسماء/أوصاف الحالات والقنوات والمجتمعات بحسب التبويب المفتوح. اختصار `Ctrl+K` يركز البحث.
4. **بطاقات المحادثات:** اسم الشخص أو المجموعة، آخر رسالة، وقت آخر نشاط، وعدد الرسائل غير المقروءة المحسوب من حالة المحادثة الحالية.
5. **إدارة المحادثات:** تثبيت/إلغاء تثبيت، أرشفة/إلغاء أرشفة، كتم/إلغاء كتم. التغييرات تستخدم حقول المستخدم الموجودة (`pins`, `arch`, `mute`) في Firestore، وتوجد شاشة لعرض المؤرشفة واستعادتها.
6. **بدء محادثة جديدة:** إدخال الرقم الشخصي ذي 10 أرقام، البحث عبر callable `resolveAccountId`، ثم فتح المحادثة من خلال وظيفة التطبيق الأصلية.
7. **القنوات:** قراءة القنوات الفعلية من `CH`، عرض المتابعين، فتح القناة ومتابعتها/إلغاء متابعتها من الوظائف الأصلية.
8. **المجتمعات:** قراءة `communities` الفعلية، البحث، والانضمام/فتح المجتمع عبر معالجات المجتمع الأصلية.
9. **التنقل:** إعادة استخدام الشريط الجانبي لسطح المكتب، وتحسين التنقل السفلي على الهاتف وإضافة اختصارات أقسام الصفحة الرئيسية.
10. **تحديث حي:** إرسال إشارة تحديث عند وصول snapshots جديدة للحالات والقنوات، والاستماع إلى أحداث تحديث المحادثات الموجودة.
11. تحديث Service Worker وملفات الإصدار، مع الإبقاء على حقول الإصدار التاريخية المتوقعة لاختبارات v222 وإضافة `currentPhase: 223` و`currentFeatureName`.

## الملفات التي تغيرت

- `site/v223-home-inbox.js` — واجهة الصفحة الرئيسية والمنطق والربط بالأنظمة الأصلية.
- `site/v223-home-inbox.css` — تصميم متجاوب لسطح المكتب والهاتف.
- `site/index.html` — تحميل CSS وJavaScript الجديدين.
- `site/chanse2/stories.js` — إطلاق حدث تحديث عند تغير snapshots للحالات والقنوات.
- `site/sw.js` — إضافة الملفات إلى precache وتحديث اسم cache.
- `site/version.json` و`site/chanse4/version.json` — بيانات المرحلة الحالية.
- `package.json` و`site/package.json` — أوامر اختبار v223.
- `scripts/v223-home-inbox-check.mjs` — اختبار تحقق ثابت للمرحلة.

- `node --check site/v223-home-inbox.js`: نجح.
- `node --check site/chanse2/stories.js`: نجح.
- `node --check site/sw.js`: نجح.
- `node scripts/v223-home-inbox-check.mjs`: نجح.
- سلامة ZIP: يتم فحصها بعد إنشاء ملفات التسليم.

## ما لم يتم التحقق منه أو نشره

- `npm run build` لم يكتمل لأن `vite` غير مثبت في بيئة التنفيذ (`vite: not found`).
- لم يتم تسجيل الدخول إلى Firebase حقيقي لاختبار المحادثة أو snapshots أو الكتابة الفعلية لحقول التثبيت/الأرشفة/الكتم.
- لم يتم اختبار العرض بصريًا على أجهزة هاتف فعلية أو متصفحات متعددة.
- لم يتم النشر إلى GitHub Pages أو نشر أي قواعد/وظائف على Firebase؛ الملفات جاهزة للرفع فقط.

## ملاحظات تشغيل

- يعتمد شريط الحالات والقنوات والمجتمعات على أن المستخدم مسجل الدخول وأن Firebase وقواعد Firestore الحالية تسمح بقراءة البيانات.
- بدء محادثة جديدة يعتمد على callable `resolveAccountId` المنشورة مسبقًا.
- لا تظهر محادثات أو حالات أو قنوات وهمية عند خلو الحساب؛ تظهر حالة فارغة بدل اختلاق محتوى.
