# تسليم THE SQUAD v210

## ما أضيف في هذا الإصدار
استوديو تصميم داخلي داخل تجربة المباني الحالية، مع قطع أثاث ثلاثية الأبعاد قابلة للإضافة والتدوير والإزالة والحفظ المحلي لكل طابق.

## طريقة التجربة
1. شغّل المشروع بعد تثبيت الاعتماديات: `npm install --no-audit --no-fund`.
2. ابدأ خادم التطوير: `npm run dev`.
3. افتح المدينة واذهب إلى مبنى قابل للدخول.
4. اضغط زر دخول المبنى، ثم اختر الطابق.
5. من استوديو تصميم الغرفة أضف القطع، ودوّر آخر قطعة أو أزلها أو امسح الإضافات.

## التحقق
- `npm test` — اجتاز كل اختبارات التدقيق والانحدار والفحص الساكن في بيئة التسليم.
- `node --check site/chanse2/district.js` — ناجح.
- `npm run build:preflight` — غير جاهز في بيئة التسليم لغياب `vite` و`esbuild` من node_modules؛ يجب تثبيت الاعتماديات قبل بناء الإنتاج.

## حدود معروفة
الأثاث الجديد مرئي فقط ولا يضيف تصادمات، وحفظه محلي للمتصفح وليس Firebase أو مزامنة متعددة اللاعبين. لم يتم نشر Firebase أو الموقع، ولم يتم إجراء اختبار WebGL حي في متصفح ضمن هذه البيئة.
