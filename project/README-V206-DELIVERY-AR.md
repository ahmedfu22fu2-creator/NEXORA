# تسليم THE SQUAD v206

## التشغيل
1. استخدم Node.js 20.19 أو أحدث.
2. من مجلد المشروع نفّذ `npm install` لتثبيت Vite وأدوات التطوير المعلنة.
3. نفّذ `npm test` لتشغيل فحوصات المشروع كاملة.
4. نفّذ `npm run dev` لتشغيل بيئة التطوير محلياً.
5. نفّذ `npm run build` بعد تثبيت الاعتماديات لإنتاج ملفات النشر.

## فتح منطقة Lifestyle
بعد تسجيل الدخول وظهور مساحة المنصة الاجتماعية، اضغط زر `Lifestyle` في الشريط العلوي. ستجد معارض السيارات والمرآب والعقارات والمحفظة والفعاليات.

## الملفات الجديدة
- `site/v206-lifestyle.js`
- `site/v206-lifestyle.css`
- `scripts/v206-lifestyle-check.mjs`
- `V206-RELEASE-NOTES-AR.md`
- `V206-IMPLEMENTATION-REPORT-AR.md`

## حالة التحقق
- `npm test`: نجح بالكامل في بيئة التسليم.
- `npm run build`: لم يُنفذ بنجاح هنا لأن Vite غير مثبت في بيئة التسليم (`vite: not found`). ثبّت الاعتماديات ثم أعد البناء.
- لم يتم نشر الموقع ولم يتم اختبار اتصال Firebase حي أو اللعب الجماعي في هذه المرحلة.
