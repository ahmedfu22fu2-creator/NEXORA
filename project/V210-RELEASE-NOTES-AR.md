# THE SQUAD v210 — تصميم الديكور الداخلي

- إضافة استوديو أثاث داخل شاشة المبنى والطابق.
- ست قطع ثلاثية الأبعاد: أريكة، سرير، مكتب، نبات، مصباح أرضي، وشاشة تلفزيون.
- تدوير آخر قطعة، إزالة آخر قطعة، أو مسح الديكور الإضافي.
- حفظ التصميم محليًا لكل مبنى وطابق واستعادته عند العودة.
- حد أقصى 24 قطعة إضافية لكل طابق.
- الحفاظ على الأثاث الإجرائي الأصلي والسلالم والمصاعد والمدينة والقيادة.

## حدود النسخة
التخصيص الحالي بصري ومحلي فقط: لا يغيّر التصادمات، ولا يتزامن بين اللاعبين، ولا يرتبط بعد بملكية العقار. أما الجراج متعدد الطوابق وحركة المرور والمحاذاة الحرة للأثاث فهي مراحل لاحقة.
