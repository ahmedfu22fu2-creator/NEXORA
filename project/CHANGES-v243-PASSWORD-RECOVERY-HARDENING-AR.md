# تغييرات v243 — تحصين استعادة كلمة المرور

- حصر طلب الاستعادة في البريد الإلكتروني الحقيقي؛ لا يُحوّل اسم المستخدم أو الرقم الشخصي إلى بريد تخميني.
- منع النقرات المتكررة أثناء الطلب وإضافة مهلة محلية قصيرة بعد الطلب الناجح أو تقييد Firebase.
- رسائل محايدة لا تكشف إن كان البريد مسجلاً، مع رسائل منفصلة لمشكلات الاتصال والصيغة والتقييد.
- إظهار حالة انشغال الزر وإعادته لحالته الأصلية بعد انتهاء الطلب.
- مزامنة ملف المصادقة مع نسختي المصدر والتسليم.
- تحديث رقم الإصدار ومساحة كاش Service Worker وإضافة اختبار انحدار.

## حدود التحقق
هذا التغيير يحسن تدفق الواجهة واستدعاء Firebase الحالي. لم يتم إرسال بريد حقيقي أو اختبار إعدادات Firebase/Authorized Domains أو فتح رابط الاستعادة في متصفح حي؛ لذلك تبقى هذه البنود NOT TESTED. الحسابات القديمة ذات `@squad.id` لم تُرحّل ولم يُنشأ لها مسار استعادة آمن في هذه الدفعة.
