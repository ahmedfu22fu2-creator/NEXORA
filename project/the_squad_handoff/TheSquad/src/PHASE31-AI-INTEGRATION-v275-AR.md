# THE SQUAD v275 — AI Integration

## ملخص الإصدار
تم تطوير نواة AI Core من منظم محلي للطلبات إلى تكامل اختياري مع مزود ذكاء اصطناعي عبر Firebase Cloud Functions. التكامل لا يعمل تلقائيًا ولا يرسل السياق أو الذاكرة دون إجراء واضح من المستخدم.

## ما تم تنفيذه فعليًا
- Cloud Function باسم `generateSquadAIResponse` باستخدام Firebase Functions v2.
- اتصال الخادم بـ OpenAI Responses API باستخدام نموذج `gpt-4.1-mini`.
- مفتاح المزود يقرأ من Firebase Secret Manager عبر السر `SQUAD_AI_API_KEY`؛ لا يوجد مفتاح API في ملفات المتصفح.
- اشتراط تسجيل الدخول، وحد أقصى 4,500 حرف للطلب.
- حدود خادمية: 8 طلبات للمستخدم في الدقيقة و60 طلبًا في اليوم، مع مهلة اتصال.
- عدم تخزين نصوص الطلبات في Firestore أو تسجيلها في سجلات الوظيفة.
- زر إرسال صريح في نافذة AI Core، يعرض موافقة قبل مشاركة النص والسياق المكتوبين.
- عرض رد المزود كنص عادي باستخدام `textContent` لتجنب تفسير HTML.
- الاحتفاظ بخيار بناء ونسخ الـPrompt محليًا إذا لم يتم نشر الوظيفة أو إعداد السر.
- تحديث الصفحة الرئيسية، Service Worker، بيانات الإصدار، واختبارات التوافق والمرايا المصدرية ونسخة Handoff.

## متطلبات التفعيل الخارجي
1. يجب على مسؤول مشروع Firebase المخوّل إعداد السر `SQUAD_AI_API_KEY` في Secret Manager.
2. يلزم التأكد من إعدادات المشروع ومزود الخدمة وحدود الإنفاق وسياسات الاستخدام قبل النشر.
3. يلزم نشر Cloud Function إلى مشروع Firebase الصحيح، ثم اختبار المصادقة وحدود الطلبات في بيئة اختبار قبل الإنتاج.
4. لم يتم نشر الوظيفة أو إعداد السر أو إرسال طلب حي إلى مزود AI في هذه المرحلة؛ لذلك التكامل البرمجي جاهز في المصدر لكنه غير مفعل إنتاجيًا بعد.
